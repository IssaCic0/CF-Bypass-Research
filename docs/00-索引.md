## 五、代码地图

```
solver/
  service.py            HTTP 服务：鉴权 / SSRF 三态守卫 / 有界准入 / 三态健康 / metrics / 优雅退出
  errors.py             错误码 + HTTP 映射（2xx 读 ok，非 2xx 读 error_code）
  cache.py              MemoryStore / FileStore / SqliteStore(WAL，v4.0 默认落盘实现)
  route.py              route=auto 决策表 + 失败原因分类（纯函数，可离线单测）
  proxypool.py          一致性哈希按域粘性 + 评分 + 冷却
  backends.py           后端协议 + 有序路由（TERMINAL_CODES 不 fallback）+ FlareSolverr
  cfsolve_backend.py    纯协议后端（调 challenge CLI）
  pydoll_backend.py     CDP 直连 Chrome 后端
  engines.py            camoufox / cloakbrowser / patchright 三引擎 + 缺依赖启动即失败
  prewarm.py            保活续期（按域退避 + 抖动）
  challenges.py         want=clearance/awswaf/turnstile/recaptcha_v3 的收集器与存根页
gocfsolve/              Go 客户端：缓存 + 提前续期 + per-host 单飞 + 回放 403 自愈 + Pool 多节点
scripts/                ab_test.py / run-pool.ps1 / verify_real.py / validate-findings.mjs
                        doctor.py(环境自检) / loadtest.py(离线压测 hot|cold|share)
                        ab_persona.py(同站双臂 persona A/B，带预算与停止条件)
                        soak.py(长跑稳定性：RSS/句柄/ready 曲线 + 四条判定)
tools/cfsolve-patches/  cfsolve 的 Windows + 运行时特征补丁（可 git apply）
run.ps1 / run.bat       统一入口：doctor / test / go / smoke / bench / verify
.github/workflows/      CI（python 覆盖率门槛 + go vet/test -race + findings，全程离线）
policy.md               质量门禁（覆盖率 80%、证据门禁、提交规则）
workflow_status.md      任务契约 / 验收表 / 验证日志 / 剩余风险
test_ledger.md          验收项 ↔ 用例映射
evidence/               验收证据（真实命令 + 真实输出）
tests/                  279 项 Python 离线测试 + 41 项 Go 测试
```
