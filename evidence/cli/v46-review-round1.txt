## Q5 Handler.inflight 计数是否可能只加不减

**REFUTED** — `service.py:2070-2083`

`_track_inflight` 是唯一入口，`enter` 在 try 之前、`exit` 在 `finally`，`do_GET`/`do_POST` 的一切异常（含 `_read_body_raw` 的 socket 超时、`_handle_shutdown` 的未捕获 raise）都必然经过 `finally`；不存在"只加不减"的调用点。两个小瑕疵：`drain()`（`2052-2063`）读 `inflight_requests` 不加锁（只影响"可能多等一轮 20ms"）；`exit_request`（`1622-1624`）无下限保护，将来若有人重复 exit 会变负、让 drain 立刻返回 0（当前无此调用点）。

## Q6 `--allow-remote-shutdown` 的风险是否被文档说清

**PARTIAL** — `service.py:1885-1893` / `docs/API.md:328`

**风险本身写清了**：`docs/项目规格.md:90` 明确"开了之后任何拿到 token 的人都能停服——token 是唯一门"；`docs/API.md:328-329`、`--help`（`2095-2096`）、`docker-compose.yml:22-25` 都解释了容器必须开 flag 的理由（客户端是 docker 网关）。

**但文档声称的行为与代码不符**：`docs/API.md:328` 写"跨机触发会 401"，而 `_handle_shutdown` 在 `do_POST` 的 `try`（`1737`）**之外**被调用（`1722-1724`），来源判定失败时 `1885-1893` 的 `raise SolveError` 无人捕获 → `_track_inflight` 只有 `finally` → `socketserver.handle_error` 打印 traceback 后直接关连接。**调用方拿到的是"无响应/连接被重置"，不是 401**，请求契约与证据（`evidence/v44-container.md:38` 记录过实测 401）都漂移了。另：`--allow-remote-shutdown` × `--no-auth` 这一组合（来源门打开、token 门关闭 = 任何人能停服）未在任何文档被点名。

证据等级：`静态确认`（控制流可读死；本想跑真实 repro，环境未授予写临时脚本的权限）。

## Q7 有没有裸 except 吞错 / TODO 占位 / 假实现

**REFUTED（无裸 except / 无 TODO / 无假实现），但有一处真缺陷** — `solver/cfsolve_backend.py:179`

- `grep` 全 `solver/`：**0 处裸 `except:`**、0 处 `TODO/FIXME/XXX`、0 处 `NotImplementedError`。所有 `except Exception` 都带 `# noqa: BLE001` + 一句为什么，多数还配了留痕（`_note_error`，如 `1142` 的 ws 守卫不可用）或计数，不属于"吞错"。

## Q8 有没有明显的安全问题（SSRF / 鉴权 / 凭证泄漏）

**PARTIAL（无高危，有一处契约缺口）** — `service.py:1041-1166` / `service.py:1667-1675`

**SSRF 做得比一般实现细**：入口 `_check_target`（`1234`、`1785`，且在**选后端之前**执行）+ 浏览器内**每个真实请求**复核（`1041-1166`，含子资源/iframe 区分与 WebSocket 独立守卫）+ 探测逐跳 `guard_hop`（`621-659`，非 http(s)/缺主机/私网三态），拦截安装失败 `fail closed`（`1123-1133`），chunked 走私入口已关（`2018-2020`）。残余：`getaddrinfo` 判定与浏览器自行解析是典型 TOCTOU，rebinding 窗口存在，被"每请求复核 + 只做正缓存"压小，属可接受并已被注释承认。

**鉴权/凭证无泄漏**：`secrets.compare_digest`（`1675`）；token 32 字节 urlsafe + `O_CREAT|O_EXCL` + 0600（`auth.py:45-72`），日志只打 SHA256 指纹；代理凭据脱敏后进 `/health`、错误消息显式剥离凭据（`1272-1278`）；审计白名单字段（`1647`）；缓存 Fernet 加密 + 目录 700/文件 600（`cache.py:626-637`）。子进程后端是 list 传参、无 `shell=True`（`cfsolve_backend.py:111`），URL 前缀已校验，不存在参数注入。

**缺口**：非回环 `/shutdown` 的拒绝路径没有响应体（见 Q6），对外契约与文档不一致；`--no-auth` 时 `_authorized()` 恒真（`1669-1671`），`/health` 会返回含 `last_error`（可能带内网主机名）/代理/域数的完整视图——仅影响显式 `--no-auth` 部署。
